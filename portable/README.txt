MindQuest - Zero-Dependency Portable Edition
============================================

You do NOT need `npm install`, `node_modules`, or PowerShell (`npm.ps1`) to run this folder!

OPTION 1: Full Edition (Solo + LAN Multiplayer) — Needs only Node.js (no npm packages)
-------------------------------------------------------------------------------------
- Windows: Double-click `start-windows.bat`
  (or open Command Prompt in this folder and run: `node server.mjs`)
- macOS / Linux: Run `bash start.sh` (or `node server.mjs`)
- Then open http://localhost:3000 in your browser.
- Share the Network URL shown in the terminal with friends on the same Wi-Fi to play Multiplayer!

OPTION 2: 100% Zero-Install Solo Edition — Does NOT even need Node.js
---------------------------------------------------------------------
- Double-click `public/offline-solo.html` to open directly in Chrome, Edge, or Firefox!
- Includes all 60 questions, 20 custom question backgrounds, animations, sound effects, and local records.
